# ✨ QuickTranslate — кросс-платформенный переводчик

Быстрый десктопный переводчик для macOS и Windows. Вызывается по глобальной горячей клавише, переводит текст через Google, Яндекс или DeepL. Поддерживает автоопределение языка, историю переводов, быструю смену направления и копирование перевода в один клик.

## 🚀 Возможности

- **Глобальная горячая клавиша** – вызов окна из любого приложения (по умолчанию `Ctrl+Q` на Windows, `⌘+Q` на Mac, можно изменить в настройках).
- **Мгновенный перевод** – ввод текста и перевод по клавише **Enter** (или **Ctrl+Enter** для многострочных случаев).
- **Автоопределение языка** – включено по умолчанию, можно вручную выбрать пару.
- **Быстрая смена направления перевода** – кнопка **⇄** между языками меняет их местами.
- **Копирование в буфер** – кнопка **📋** рядом с результатом, с анимацией подтверждения.
- **Очистка поля после перевода** – чекбокс для автоматической очистки ввода.
- **История переводов** – последние 20 переводов с возможностью копирования.
- **Тёмная тема** – стильный интерфейс с фиолетовыми акцентами, градиентами и плавными анимациями.
- **Перетаскиваемое окно** – можно схватить за любое место и перенести.
- **Кроссплатформенность** – работает на Windows (10/11) и macOS (10.14+).
- **Локальное хранение настроек** – все конфигурации (включая API-ключи) хранятся в защищённой папке (`%APPDATA%/QuickTranslate` на Windows, `~/Library/Application Support/QuickTranslate` на macOS).

## 📦 Установка и запуск

### Из исходников (Python)

1. Убедитесь, что у вас установлен **Python 3.7+**.
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/yourusername/quicktranslate.git
   cd quicktranslate
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите приложение:
   ```bash
   python translator_app.py
   ```

### Собранное приложение (Windows)

1. Скачайте последнюю версию `QuickTranslate.exe` из раздела [Releases](https://github.com/skywaJlker192/QuickTranslate/releases/tag/v1.0.0).
2. Запустите файл от имени администратора (правый клик → «Запуск от имени администратора»). Это необходимо для работы глобальных горячих клавиш.
3. Чтобы программа запускалась при старте системы, добавьте её в планировщик задач с высшими правами (см. ниже).

### Собранное приложение (macOS)

1. Скачайте `QuickTranslate.app` из раздела [Releases] ##СДЕЛАЮ ПОЗЖЕ ТК МАКА НЕТУ СЕЙЧАС
2. Перенесите приложение в папку «Программы».
3. При первом запуске macOS может запросить разрешение на «Универсальный доступ» (System Preferences → Security & Privacy → Privacy → Accessibility). Нажмите «+» и добавьте `QuickTranslate.app`.
4. Запускайте приложение как обычную программу.

## ⌨️ Горячие клавиши

- **Вызов окна**: `Ctrl+Q` (Windows) или `⌘+Q` (macOS) – можно изменить в настройках.
- **Перевод**: `Enter` в поле ввода.
- **Многострочный ввод**: `Ctrl+Enter` вставляет перенос строки.
- **Копирование перевода**: клик по кнопке **📋**.

## 🌐 Поддержка сервисов перевода

QuickTranslate поддерживает три сервиса. Google Translate работает без ключа, но может быть менее стабилен. Рекомендуем подключить Яндекс или DeepL для гарантированной работы.

| Сервис | Бесплатный лимит | Требуется ключ |
|--------|-------------------|----------------|
| Google Translate | Без лимита, но может быть заблокирован | Нет |
| Yandex Translate | Бесплатно для тестирования | Да |
| DeepL Translate | 500 000 знаков в месяц | Да |

### Как получить API-ключ

#### Яндекс.Переводчик
1. Зайдите в [Яндекс Cloud](https://cloud.yandex.ru) и создайте аккаунт.
2. В консоли управления создайте сервисный аккаунт с ролью `ai.translate.user`.
3. В разделе «Сервисные аккаунты» нажмите на созданный аккаунт → «Создать новый ключ» → «Создать API-ключ».
4. Скопируйте ключ и вставьте в настройках QuickTranslate (вкладка Yandex Key).

#### DeepL
1. Зарегистрируйтесь на [DeepL API](https://www.deepl.com/pro?utm_source=github&utm_medium=github-python-readme#developer).
2. В разделе «API Keys» создайте новый ключ (бесплатный план, суффикс `:fx`).
3. Вставьте ключ в настройках QuickTranslate (вкладка DeepL Key).

## ⚙️ Сборка из исходников

Для создания автономного исполняемого файла используйте **PyInstaller**:

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name "QuickTranslate" translator_app.py
```

Готовый файл появится в папке `dist`.

## 🪄 Автозапуск в Windows (через Планировщик задач)

Чтобы переводчик стартовал вместе с системой и работали горячие клавиши:

1. Откройте «Планировщик задач» (`taskschd.msc`).
2. Нажмите «Создать задачу».
3. **Вкладка «Общие»**:
   - Имя: `QuickTranslate`
   - Отметьте «Выполнять с наивысшими правами»
4. **Вкладка «Триггеры»** → «Создать»:
   - «При входе в систему»
5. **Вкладка «Действия»** → «Создать»:
   - Действие: «Запуск программы»
   - Программа: укажите путь к `QuickTranslate.exe`
6. Нажмите «ОК» и подтвердите права администратора.

- Глобальные горячие клавиши на Windows требуют прав администратора.
- Сочетание с обратным апострофом (`Ctrl+`` `) не поддерживается библиотекой `keyboard`; используйте буквенные или стрелочные комбинации.
- При использовании Google Translate без ключа возможны блокировки при частых запросах. Рекомендуется подключить ключ Яндекс или DeepL.
